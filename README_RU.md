# Ultimate Local AI — техническое описание

**Разработчик:** Яхлов Андрей Васильевич  
**Тип проекта:** инициативная локальная разработка для Windows.

## Для чего создана программа

Проект создан разработчиком по собственной инициативе для рабочих условий, где интернет отсутствует или ограничен, а доступные компьютеры могут быть старыми или маломощными. Цель — запускать локальные GGUF-модели без облака и без необходимости вручную подбирать десятки параметров под каждый ПК.

Программа автоматически определяет CPU, AVX/AVX2, общий и свободный объём RAM и доступную видеокарту, после чего выбирает совместимый CUDA/Vulkan/CPU backend и рабочие runtime-параметры.

## Backend

CPU:
- `cpu-avx`;
- `cpu-avx2`.

NVIDIA CUDA:
- `cuda-pascal-avx`;
- `cuda-modern-avx2`;
- `cuda-blackwell-avx2`.

Vulkan:
- `vulkan-avx`;
- `vulkan-avx2`.

Порядок Auto: `NVIDIA CUDA → Vulkan → CPU AVX2 → CPU AVX`.

## Адаптация к слабым ПК

Auto Runtime учитывает общий объём RAM, реально свободную RAM перед запуском, размер GGUF, поддержку AVX2, VRAM и число CPU-потоков. При дефиците памяти уменьшаются context и batch/ubatch, а часть CPU-потоков оставляется системе.

## Portable

Готовой сборке не нужны Visual Studio, .NET SDK, CMake, CUDA Toolkit или Vulkan SDK. Для GPU требуется совместимый драйвер.
