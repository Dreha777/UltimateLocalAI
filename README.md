# Ultimate Local AI

**Разработчик:** Яхлов Андрей Васильевич

Ultimate Local AI — портативное Windows-приложение для локального запуска GGUF-моделей искусственного интеллекта через `llama.cpp`.

Проект создан **по личной инициативе разработчика** для рабочих условий, где интернет отсутствует или ограничен, а компьютеры могут быть сравнительно маломощными и сильно отличаться по конфигурации. Основная идея — дать пользователю готовый локальный ИИ-интерфейс, который сам определяет оборудование и выбирает подходящие параметры без обязательной ручной настройки.

## Назначение

Программа предназначена для автономной работы с локальными GGUF-моделями на Windows:

- локальный streaming-чат без обязательного облачного сервиса;
- автоматическое определение CPU, AVX/AVX2, RAM и GPU;
- автоматический выбор совместимого backend;
- автоматическая адаптация context, threads, batch/ubatch и GPU offload;
- работа на старых AVX-only CPU;
- NVIDIA CUDA backend для поддерживаемых поколений;
- универсальный Vulkan fallback для AMD, Intel и других совместимых GPU;
- локальная история чатов, вложения, база знаний и диагностические логи;
- красивое отображение LaTeX-формул и цветных блоков программного кода;
- копирование отдельных сообщений и экспорт чата в Word-совместимый RTF или PDF;
- монитор CPU/RAM/GPU/VRAM и несколько тем интерфейса.

## Автоматический выбор backend

В режиме `Backend = Auto`:

`совместимый NVIDIA CUDA → Vulkan → CPU AVX2 → CPU AVX`

В Portable предусмотрены `cpu-avx`, `cpu-avx2`, `cuda-pascal-avx`, `cuda-modern-avx2`, `cuda-blackwell-avx2`, `vulkan-avx` и `vulkan-avx2`.

Перед загрузкой модели программа учитывает не только установленную RAM, но и реально свободную память, оставляя запас для Windows. На слабых ПК context и batch автоматически уменьшаются.

## Быстрый запуск

1. Скачайте артефакт **UltimateLocalAI-Portable-ZIP** из успешного workflow **Build Windows Portable**.
2. Распакуйте архив.
3. Запустите `UltimateLocalAI.exe`.
4. Нажмите **«Выбрать GGUF»** и укажите локальный файл модели `.gguf`.
5. Оставьте `Backend = Auto`.
6. Нажмите **«Запустить»** и дождитесь состояния **«Модель готова»**.
7. Введите запрос. `Enter` — отправить, `Shift+Enter` — новая строка.
8. Для освобождения RAM/VRAM используйте кнопку **«Выгрузить»**.
9. Кнопка **«Экспорт»** сохраняет беседу в Word-совместимый RTF или PDF; каждое сообщение можно скопировать отдельно.

Полная инструкция находится в `USER_GUIDE_RU.txt` и доступна из окна **«Справка / О программе»**.

## Данные и конфиденциальность

Основные рабочие данные сохраняются локально рядом с программой:

- `Data/config.json` — настройки;
- `Data/chats.json` — история чатов;
- `Data/knowledge.json` — локальная база знаний;
- `Logs/` — диагностические журналы.

Inference выполняется отдельным локальным процессом `llama-server`, к которому GUI обращается через loopback-интерфейс `127.0.0.1`.

## Runtime

- **Stable** — зафиксированная проверенная версия `llama.cpp`;
- **Latest** — актуальный runtime для новых GGUF-архитектур и GPU;
- **Custom** — пользовательская папка runtime.

## Открытые компоненты

Ultimate Local AI разработана с использованием открытых компонентов. Ключевой inference-движок — **llama.cpp / ggml-org**, лицензия MIT.

Подробности и ссылки на сторонние компоненты приведены в `THIRD_PARTY_NOTICES.md`.

**GGUF-модели не входят в состав программы** и могут иметь собственные лицензии и условия использования.

## Документация

- `FIRST_START_RU.txt` — краткий первый запуск;
- `USER_GUIDE_RU.txt` — руководство пользователя;
- `THIRD_PARTY_NOTICES.md` — сторонние компоненты и лицензии;
- встроенное окно **«Справка / О программе»** — сведения о разработчике, назначении и быстрый старт.

## Сборка

Основная Portable-сборка создаётся GitHub Actions. Готовой сборке на целевом ПК не нужны Visual Studio, .NET SDK, CMake, CUDA Toolkit или Vulkan SDK. Для GPU требуется совместимый системный драйвер.
