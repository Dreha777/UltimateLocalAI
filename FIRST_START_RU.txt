ULTIMATE LOCAL AI PORTABLE — ПЕРВЫЙ ЗАПУСК

Разработчик: Яхлов Андрей Васильевич

НАЗНАЧЕНИЕ
Ultimate Local AI — портативный Windows-клиент для автономного локального запуска GGUF-моделей через llama.cpp.

Проект создан по личной инициативе разработчика для рабочих условий с отсутствующим или ограниченным доступом в интернет и сравнительно маломощными/разнородными ПК. Основная задача — автоматически подобрать совместимый backend и параметры работы под конкретный компьютер.

БЫСТРЫЙ СТАРТ
1. Запустите UltimateLocalAI.exe.
2. Нажмите «Выбрать GGUF» и укажите модель .gguf.
3. Оставьте Backend = Auto.
4. Нажмите «Запустить» и дождитесь надписи «Модель готова».
5. Введите запрос. Enter — отправить, Shift+Enter — новая строка.
6. Кнопка «Выгрузить» завершает llama-server и освобождает RAM/VRAM.

AUTO
Программа автоматически определяет CPU, AVX/AVX2, количество потоков, общий и свободный объём RAM и доступную GPU.

Приоритет backend:
- совместимый NVIDIA CUDA;
- Vulkan для AMD / Intel / других совместимых GPU;
- CPU AVX2;
- CPU AVX.

Context, threads, batch/ubatch и GPU layers в Auto подбираются автоматически.
На слабых ПК программа уменьшает требования и оставляет запас памяти для Windows.

ДАННЫЕ И ДИАГНОСТИКА
Logs\localai_YYYYMMDD.log — журнал работы.
Data\config.json — настройки.
Data\chats.json — история чатов.
Data\knowledge.json — локальная база знаний.
